# City Apps — public demonstration

عرض تفاعلي مبسط مستقل لسيتي شوب وسيتي درايف. جميع البيانات وهمية؛ ليس نسخة الإنتاج ولا يتضمن شيفرة الخادم الخاص أو بيانات العملاء.

Open index.html in a browser. No dependencies, network requests, credentials, payments, phone numbers or location collection. This repository is intentionally separate from the private original application's Git history.

The four demonstration stages are local UI simulation, not proof of backend execution. Do not enter real customer data. Production deployment is tracked separately in the private repository.
